# Security Policy

Please report suspected vulnerabilities privately to the repository maintainer, [mixxermannipro](https://github.com/mixxermannipro). If GitHub private vulnerability reporting is enabled, use **Security → Report a vulnerability**. Otherwise request a private contact channel from the maintainer.

Include affected versions, reproduction steps, expected impact, and suggested mitigations where possible. Do not disclose credentials, personal data, or exploit details in public issues or pull requests. Please allow time for coordinated remediation before public disclosure.

Do not commit API keys, signing keys, access tokens, passwords, or private user data. Keep local configuration and signing material outside version control.
