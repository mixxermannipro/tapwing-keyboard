# Tapwing Architecture Analysis (`v2.9.0`, `versionCode = 17`)

For current dependency versions and build configuration see [gradle/libs.versions.toml](gradle/libs.versions.toml) and [app/build.gradle.kts](app/build.gradle.kts); for licensing details see [docs/licensing.md](docs/licensing.md) and [REUSE.toml](REUSE.toml).

## Core Architecture Overview

| Layer / Module | Key Components | Security & Privacy Boundary |
| :--- | :--- | :--- |
| **IME Core (`ime/`)** | `TapwingInputMethodService`, `EditorField`, `SensitiveEditorGuard`, `ImeProfileLearningController`, `UndoManager` | Enforces Direct Boot unlock awareness (`ACTION_USER_UNLOCKED`), blocks profile/stats/clipboard recording in password/OTP/card/`NO_PERSONALIZED_LEARNING` editors, and binds editor-scoped profile learning tokens cleanly. |
| **Keyboard UI (`ui/keyboard/`, `ui/theme/`)** | `TapwingKeyboardRoot`, `KeyboardGrid`, `SuggestionStrip`, `TapwingTheme` (`SLATE`, `COBALT`, `EXPRESSIVE_LAVENDER`, `DYNAMIC`, `AMOLED_DARK`), plus 6 split panel files (`InlinePanels.kt`, `ToolsGridPanel.kt`, `WritingAidPanel.kt`, `ClipboardPanel.kt`, `EmojiPanel.kt`, `VoicePanel.kt`) | Renders translucent Glass mode (`appleModeEnabled`), WCAG-AAA contrast, customizable Quick Bar (`QuickBarAction`), visible active-cloud indicator badge when cloud providers are used, and isolated `safeRunPanelAction` click handlers. |
| **Data & Storage (`data/`, `clipboard/`, `dictionary/`)** | `TapwingPreferencesRepository` (DE non-secret prefs), `PersonalProfileStorage` (CE + AndroidKeyStore AES-256-GCM + `KEY_INITIALIZED`), `SecureKeyStorage` (CE + AndroidKeyStore AES-256-GCM), `StorageMigration` (DE->CE migration + zero-fill `secureDelete`), `ClipboardStore`, `TypingStatsStore`, `AdaptiveDictionaryStore` | Strict DE/CE split: only UI/layout preferences remain in DE storage for Direct Boot; all PII, clips, keys, adaptive N-grams, and stats stay exclusively in CE storage after user unlock. Legacy DE files are securely wiped after migration. |
| **Models, Downloads & AI (`ai/`, `voice/`)** | `LocalModelCatalog` (17 pinned models), `OfflineDictionaryPackManager` (9 FrequencyWords packs), `DownloadIntegrityVerifier`, `LocalModelManager`, `LocalLlmEngine`, `SherpaOnnxEngine`, `CloudProviderPolicy`, `CloudAiClient`, `OpenSourceLicensesCatalog` | Commit-pinned HTTPS downloads verified via exact byte size + SHA-256 before extraction/activation; `CloudAiClient` restricts cleartext HTTP strictly to loopback (`localhost`, `127.0.0.1`, `::1`); `LocalLlmEngine` auto-unloads after 120s idle & `onTrimMemory`; cloud features require explicit per-provider opt-in consent. |
| **OCR (`clipboard/`, `ime/`)** | `ScanTextActivity` (CameraX + on-device ML Kit), `ScreenshotMonitor` (`PickVisualMedia` + local cache) | Zero storage/media permissions (`READ_MEDIA_IMAGES` and `READ_EXTERNAL_STORAGE` removed). |
| **Settings UI (`settings/`)** | `SettingsActivity`, `SettingsNavigation`, `SettingsScreens`, `SettingsSharedComponents`, `SettingsBasicsScreen`, `SettingsTypingScreen`, `SettingsAppearanceScreen`, `SettingsDictionaryScreen`, `SettingsProfileScreen`, `SettingsClipboardScreen`, `SettingsDictationScreen`, `SettingsWritingAidScreen`, `SettingsApiKeysScreen`, `SettingsPrivacyScreen`, `SettingsAboutAndLicensesScreen` | Searchable modular UI featuring opt-in confirmation for `smartProfileAutoLearn`, individual/bulk deletion of learned values, per-provider `CloudConsentDialog`, live revocation screen, and full library/model license catalog. |
| **Build, Quality & CI** | `gradle/libs.versions.toml`, `Kover 0.9.11`, Android Lint + `lint-baseline.xml`, `.github/workflows/ci.yml`, `.github/dependabot.yml`, `scripts/check-docs-version.sh`, `scripts/build-release.sh` | Enforces doc/version sync, unit tests, lint checks, `arm64-v8a` ABI size monitoring, and 16 KB ELF `PT_LOAD` page alignment. |
